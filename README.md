# CSPSI Project - Frustrated AF Spin Chain SSE QMC

This report focuses on the simulation of a frustrated anti-ferromagnetic (AF)
spin chain using stochastic series expansion quantum Monte-Carlo techniques.
Hereby, we provide the source code used when running the simulations presented
in the associated report, as well as the LaTeX code generating the report.
The implementation is realized using C++11.

## Requirements
This project uses relies on (and compiles with) the following piece of software:
- g++ (version 8.2.1 20181127)
- make (version 3)
- Matlab (version 9.4.0.813654 (R2018a), no toolboxes required)
- Mathematica (version 11.3.0.0)
- Doxygen (version 11.8.14)
- sed, required by Matlab routines (version 4.5)

## How to browse this report?
This README file is located at the root of the `Codes.zip` archive. The
contents of the report are then split in subsequent folders:
- `CPPv1/`: Code, makefile, input configurations and documentation of the first version of the code. This version performs a SSE QMC simulation of a spin half Heisenberg chain.
- `CPPv2/`: Code, makefile, input configurations and (partial) documentation of the expansion of the code to the frustrated AF chain described in the report. It compiles and runs simulations for the Heisenberg chain, but has _failing_ implementation of the frustrated AF chain. It is included for completness.
- `Results`: A collection of outputs, used for testing convergence and accuracy of the former codes. Results with time stamp `1811**` were performed using version 1, those with `1812**` originate from version 2.
- `Mathematica`: Scripts computing the exact diagonalization of the two considered systems, documentation for those scripts is found in the form of comments within them.
- `Matlab`: Scripts for importing simulation results or running parameter scans.
- `Report/`: LaTeX source code generating the report. It requires the following packages,
  * AMS suite, braket, bm and bbm for mathematical notations
  * Hyperref, cleverref, caption, footmisc for captioning and references
  * TiKz (with the calc and fit libraries), forloop and graphicx for graphical elements
  * Algorithm and algpseudocode for pseudo-code write up.

## Compiling and running
In order to build the program, it should be sufficient to run a simple

```
make
```

This command can alternatively be called with arguments `clean` (removes build
files and executable) or `cleandocs` removes the documentation generated by
Doxygen.

The documentation is built using:
```
doxygen doxydocs
```

Where `doxydocs` contains the confguration parameters read by Doxygen.

## Remarks
### Main differences between v1 and v2
We mentionned two versions of the code, where the second was said to be included
for completness. While the first version follows closely the suggested
implementation described in the report. The algorithms are therefore suited
specifically to the Heisenberg half spin chain.

Although the second version yields similar results for the Heisenberg chain, it
also generalizes the formerly described structure to enable implementation of
more complex systems. Basically, this is equivalent to encapsulating the system
dependent physics in a `qmc::Lattice` child class. The reader is invited to
browse the code documentation in order to get an idea of its structure.
